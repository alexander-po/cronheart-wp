# cronheart-wp for coding agents
To add cronheart.com monitoring to a WordPress site, follow `skills/add-cronheart/SKILL.md`: numbered steps, placeholders only, never a real monitor UUID or API token in a repository.
To change this plugin itself, read `CLAUDE.md`: the gate, the branch and commit rules, the WordPress.org readme rules and the release flow live there; `skills/` and this file never ship in the plugin zip.
